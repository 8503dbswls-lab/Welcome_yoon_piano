# 윤피아노교습소 홈페이지

GitHub Pages에 바로 배포할 수 있는 정적 홈페이지입니다.

## GitHub Pages 배포 방법

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 `index.html`과 `README.md`를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`를 선택한 뒤 저장합니다.
6. 잠시 후 표시되는 홈페이지 주소로 접속합니다.

## 다음 교체 항목

- Hero 실제 공간 사진
- 원장님 사진
- 공간 갤러리 사진
- 전화번호
- 상세 주소
- 네이버 플레이스 주소

현재 확인되지 않은 정보는 홈페이지에서 사실처럼 표시하지 않고, 교체 예정 문구로 구분해 두었습니다.
